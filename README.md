# Mantık Laboratuvarı

Tarayıcıda çalışan, dokunmatik ekran destekli mantık devresi simülatörü.

- Anahtar, lamba, AND, OR, NOT ve XOR parçalarını ekle; sürükleyerek taşı.
- Giriş ve çıkış uçlarını kabloyla bağla; anahtarlara dokunarak sinyali izle.
- Sağdaki **Doğruluk Tablosu** panelini açıp 0/1 kombinasyonlarını ve lambaların mantık ifadelerini gör.
- **Örnek devre** ile yarım toplayıcıyı dene.

Kurulum gerekmez: `index.html` dosyasını tarayıcıda aç veya GitHub Pages ile yayımla. Devre tarayıcıda yerel olarak kaydedilir. Doğruluk tablosu en fazla 6 anahtarlı kombinasyonlar için üretilir.
